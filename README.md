# Курсовая: поиск гамильтоновых циклов на языке C

## Состав
- `main.c` — консольное приложение.
- `triangle.txt` — неориентированный треугольник (один гамильтонов цикл).
- `directed_cycle.txt` — ориентированный цикл из четырёх вершин.
- `no_cycle.txt` — граф без гамильтонова цикла.

## Сборка
GCC / MinGW:
```bash
gcc -std=c11 -O2 -Wall -Wextra -pedantic main.c -o hamilton
```
Запуск:
```bash
./main.exe
```
В Windows:
```bat
main.exe
```

## Формат файла
Первая строка содержит два целых числа: `directed n`.
`directed=0` означает неориентированный граф, `directed=1` — ориентированный.
Далее идут `n` строк матрицы смежности, элементы 0 или 1.

## Важное замечание
Алгоритм использует полный перебор с возвратом. В худшем случае время работы
экспоненциальное (порядок факториального роста), поэтому для больших плотных
графов поиск всех циклов может занимать значительное время. Для экспериментов
по времени в меню предусмотрено ограничение размера графа до 15 вершин.
